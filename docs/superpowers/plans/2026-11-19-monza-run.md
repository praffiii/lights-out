# His run from 19th: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The Monza band on `/people/antonelli` drives Antonelli's real lap 1 of the 2026 Italian GP. A purple car leaves Grid 19, and a chip counts his position (`ANT · P19` … `ANT · P14 · after lap 1`). The car loops, while the tags, toggles and Explore link stay.

**Architecture:**
- **Recorded data.** The raw OpenF1 lap-1 data for car 12 is recorded once as a test fixture.
- **A standing start.** `alignLap` learns a standing start, so lap 1 runs from the grid slot to the line.
- **The baked run.** A pure `bakeRun` turns the raw data into `src/people/monza-run.json`. A pure `runAt` reads it at any moment.
- **The display.** A small `RunHud` draws the car and chip on the stage's projected trace, with the same helpers `PassHud` uses. `CircuitStage` gains `controls` so a HUD can keep the toggles.

**Tech Stack:** React, three.js (R3F, already in place), plain CSS, Effect Schema, bun test with happy-dom, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-19-monza-run-design.md`

it('keeps the session, the lap time and every position update in lap time', () => {

  expect(RUN.time).toBe(95.76)

  expect(runAt(RUN, 200)).toMatchObject({ position: 14, done: true, u: 1 })
